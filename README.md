# Palette Helper for Aseprite
A tool to quickly and easily generate gradients.

**More information and downloads at itch.io: [Palette Helper for Aseprite](https://chaonic.itch.io/aseprite-palette-helper)**

## Installation Instructions (as of Aseprite v1.3.18)
1. Download [latest release at itch.io](https://chaonic.itch.io/aseprite-palette-helper) or through Github Releases (itch.io recommended)
2. Unzip the file
3. Open Aseprite, and navigate to: `File -> Scripts -> Open Scripts Folder`
4. Move the `.lua` file from the extracted `.zip` from step 2 into the opened scripts folder
5. Run `File -> Scripts -> Rescan Scripts Folder` (If the script does not show in `File -> Scripts`, you may have to restart Aseprite)
6. Click on the `chaotics_palette_helper` option in `File -> Scripts`
7. Accept the Aseprite warning if it shows up
8. The Palette Helper window should open!
